# Discord Frame Picker

[![Twitter](https://img.shields.io/badge/Twitter-@Squarezum-ffffff.svg?style=plastic&logo=X)](https://x.com/Squarezum) [![Discord](https://img.shields.io/badge/Discord-Skibidi%20Rizzlers-5865F2.svg?style=plastic&logo=Discord)](https://discord.gg/WUbkndNBjA) [![Tiktok](https://img.shields.io/badge/tiktok-@Squarezum__-000000.svg?style=plastic&logo=Tiktok)](https://www.tiktok.com/@squarezum_)


Discord Frame Picker is a bot that posts random frames from a movie, series or video game when an user asks for it. You can see it in action with [my MGS Frames bot](https://x.com/Squarezum/status/2018753751583211831)

It pretty much just chooses a random image from a folder, so it doesn't really have to be frames of something really.

Keep in mind that I'm a very very very much a beginner, so this code might suck (but if it works, it works).
## Installation

Make sure to download all the requirements, that being **discord.py** and **python-dotenv**

```bash
pip install -r .\requirements.txt
```

## Usage

All you really have to do is add your bot token in the **.env** file and run **main.py** on the machine you want to host the bot on

If you don't have a bot already you can [follow the official guide here](https://discord.com/developers/docs/quick-start/getting-started)
